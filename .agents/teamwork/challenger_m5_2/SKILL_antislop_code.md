# antislop-code (Local copy)
Source: C:\Users\fahmi\.gemini\config\skills\antislop-code\SKILL.md

Code comment hygiene for AI coding agents: remove generic AI-slop comments, keep the valuable ones, never touch the code.
- Decorative Separators (banners, boxes, ALL CAPS)
- Restating the Obvious
- Workflow Narration (Step 1, Step 2, etc.)
- Empty Labels
- Vague Placeholders
- Signature Echo
- Decorative Emoji
- End Markers
- Over-Explained Comments
- Line-by-Line Narration
- Stiff or Loud Wording
- Guardrail: Never modify executable code.
